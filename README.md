# Application Fill

Application Fill 是一个本地优先的求职表单辅助浏览器扩展。它不会猜测网页字段、更不会自动提交：在网页中选中一个填写框，再从右侧资料面板点击想填入的资料即可。

## 功能

- Chrome 与 Safari 的同一套扩展源码
- 独立的中文、英文资料档案
- 基础资料、教育、实习、项目、校园经历、语言、兴趣爱好、个人评价、链接与常用问答
- Finance、Tech、AI PM 等可切换的实习经历版本
- 本地浏览器存储；无账号、无追踪、无服务器、无自动提交
- 支持文本框、多行文本、常规下拉菜单、复选框和单选框

## 使用方式

1. 安装扩展后，点击工具栏中的 Application Fill 图标。
2. 选择网页里的一个可填写字段。
3. 在右侧面板中选择中文或英文资料，并点击想填入的内容。
4. 在面板底部点击“编辑资料”，在本地补充自己的资料。
5. 请在提交申请前逐项检查。

## 本地安装（Chrome）

1. 下载或克隆此仓库。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本仓库目录。

## Safari

此项目使用标准 Manifest V3 Web Extension 结构。通过 Xcode 的 Safari Web Extension Converter 将本目录转换为 Safari 扩展项目，构建后在 Safari 的“设置 → 扩展”中启用。

## 隐私

真实资料只保存在浏览器本地。请不要将个人简历、身份证号、电话号码或任何真实资料提交到本仓库、Issue 或截图中。
